# 4NiK8.art

Landing page for **www.4NiK8.art** — underground art, punk, and comix from
SlugDen Studios, Jasonville, IN.

Hosted free on GitHub Pages. Single static page (`index.html`, no build step).

## Sections

- **Listen** — Apple Music: Ryan White and the HIV Positive All Star Band
  playlist, plus Slug Muffin, The MKultra Project, Tenstrip, and PsydeEffects.
- **Play** — Glyfop-771, the 2D side-scroller (public link).
- **Read** — RED FLOW teaser (in development, not published).
- **Shop** — Three Printify stores: SlugDen Studios Music, Niche Novelty Nest,
  School Spirit.
- **Watch** — TikTok (@4nik8.art) and Instagram (@4nik8art).
- **Downloads** — Coming soon: albums and art direct from shared folders.
- **Visit** — SlugDen Studios, 121 S Washington St, Jasonville, IN.

## Custom domain

DNS at Squarespace points `www.4nik8.art` at GitHub Pages. The `CNAME` file
is added when the DNS cutover happens — not before, so the
`github.io` preview URL keeps working until then.
